# v1.2.62 新功能
新增**插件更新检查**功能。现在在插件首选项页面可以自动检查插件是否有更新版本，并提示用户更新，并新引入功能介绍功能。首选项页面还可以检查不同版本的具体更新日志，并回顾所有版本的功能介绍

# v1.2.6 新功能
新增**自定义标签悬浮卡片预览图**功能。考虑到某些文献名称很相近，放在一起也不是很好辨认。但是文献中某些图或功能能给人留下深刻印象，现在支持对标签自定义截取原图，来更快速地分辨不同的文献！
* 实现步骤：进入阅读器，滚动到想要截屏的位置后，在垂直侧边栏的标签处"右键"->"截取预览图"，进入截屏模式，在文献中框选截屏区域，即可完成预览图自定义。
![预览图说明](CardFigs.gif)
* 预览图跟随标签id，标签关闭后下次恢复预览图依旧存在。注意预览图保持和卡片一样的宽度，但高度有上限，超过最高高度的部分不会显示，所以过狭长的图片只会展示上方区域，推荐使用横向比例截图。
