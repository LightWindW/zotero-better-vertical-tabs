一个适配 Zotero 主页面、PDF 阅读页面的垂直标签栏插件。

本插件旨在通过垂直标签栏的方式管理已经打开的标签页，帮助用户更快速地定位标签、切换视图，并对标签进行分类整理。

---

# 🧩 功能预览

## 1️⃣ 主页面

加载插件后，主页面最左侧会出现垂直标签栏（VT）。鼠标悬停在该区域时 VT 会自动展开，移出后自动折叠。

<img src=".\figs\VT.gif" />

目前主页面 VT 已实现：

1. **标签同步**：与 Zotero 原生标签栏保持同步，附件条目显示父条目图标。

2. **悬浮详情卡片**：鼠标悬停在标签上时显示条目详细信息。

3. **搜索标签**：在顶部搜索框快速过滤已打开的标签。

4. **拖拽整理**：支持拖拽标签调整顺序或归类，整个分类也可以统一拖拽。可使用 **Ctrl/Shift+左键**多选标签进行批量拖拽。

5. **分类保存与导入**：可将常用分类保存到本地，需要时一键导入。

   <img src=".\figs\Category.jpg" />

## 2️⃣ 分类创建

本插件提供三种方式新建分类，方便用户按项目、主题或阅读计划组织标签：

- **① 右键菜单新建**：选中一个或多个标签后右键 →「添加分类」。

  <img src=".\figs\add1.jpg" width="300" />

- **② 拖拽至 "+ 新建分类" 落区**：将标签拖拽到侧边栏顶部的虚线框，松开即创建新分类。

  <img src=".\figs\add2.gif" width="300" />

- **③ 更多菜单新建**：点击右上角「更多」→「添加分类」，创建空分类后可拖入标签。

  <img src=".\figs\add3.jpg" width="300" />

## 3️⃣ 展开模式

插件的「更多」菜单提供三种侧边栏展开模式，适配不同使用习惯：

| 模式     | 行为                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| **自动** | 鼠标悬停折叠条时自动展开、移出自动折叠，适合快速翻阅标签                     |
| **手动** | 悬停不展开，需点击 Pin 按钮才展开，展开后保持打开直到再次点击 Pin 按钮折叠   |
| **最小** | 同手动模式，但折叠条进一步收窄为仅图标的 20px 条，适合追求最小视觉干扰的用户 |

模式切换后立即生效，所有窗口同步。

## 4️⃣ PDF 阅读器管理

Zotero 的 PDF 阅读器在沙盒中运行，打开越多内存占用越大。本插件提供以下工具帮助管理阅读器资源：

- **绿色高亮指示条**：左侧带有已打开 PDF 阅读器的标签，最左边会显示一条绿色竖线，一眼可辨（可在首选项中关闭）。

- **手动关闭/打开阅读器**：标签右键菜单 →「关闭阅读器」/「打开阅读器」可即时释放内存，不影响标签本身。

- **自动关闭闲置阅读器**：默认开启，插件会自动关闭超过指定分钟数未阅读的 PDF 阅读器。默认 120 分钟，可在「首选项」中调整或关闭。

## 5️⃣ 自动关闭闲置标签

为避免标签栏堆积过多长期未读的标签，插件支持自动关闭超过指定天数未读的标签。

- **默认不开启**：需在「首选项」中手动启用。
- 可设置关闭天数阈值，超过该天数未阅读的标签将被自动关闭。

## 6️⃣ 首选项设置

插件提供以下首选项（`编辑` → `首选项` → `Better Vertical Tabs`）：

- **标签高度自定义**：调整 VT 中单个标签项的显示高度。
- **展开模式切换**：在自动 / 手动 / 最小三种模式间切换。
- **启用磨砂效果**：在弹窗/悬浮卡片中使用磨砂背景，兼容不支持 `backdrop-filter` 的环境或用户个人偏好。
- **PDF 阅读器高亮指示**：对已打开 PDF 阅读器的标签显示绿色指示条，可关闭。
- **自动关闭闲置阅读器**：开启后，超过 X 分钟未阅读的 PDF 阅读器自动关闭。
- **自动关闭闲置标签**：开启后，超过 X 天未阅读的标签自动关闭，默认关闭。

# 🚀 安装方式

1. 在 Release 页面下载 `.xpi` 插件文件。
2. 打开 Zotero，点击顶部菜单栏中的 `工具` → `插件`。
3. 点击右上角齿轮图标 → `从文件安装插件`。
4. 选择下载的 `.xpi` 文件并安装。
5. 安装完成后重启 Zotero 即可生效。

---

# ⚠️ 可能存在的 bug

1. 目前 VT 只实现了对 Zotero 原生标签单方面的顺序同步：拖拽原生标签栏不会同步改变 VT 的顺序，可能造成显示不一致。建议尽量使用 VT 管理标签顺序。或者在“更多->关闭原生标签”，只显示垂直标签栏。
